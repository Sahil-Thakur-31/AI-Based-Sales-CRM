Admin Dashboard

The Admin Dashboard shows overall sales health for all non-admin active users. It pulls data from adminDashboardService.js (line 86) and the screen is built in AdminHome.jsx (line 424).

What you see on the dashboard:

Revenue (Won): total value of deals that are Closed Won (stage = P7) inside the selected date range.
Active Deals: current open deals count. It excludes won and lost deals, so only live deals are counted.
Win Rate: percentage of won deals out of total closed deals in the selected range. Formula is won / (won + lost).
Pipeline Value: total money value of all currently open deals.
Open Leads: active leads not yet converted to deals and not in stage P7.
Lead Pipeline / Deal Pipeline: stage-wise count and amount.
Deal Pipeline shows deals by stage.
Lead Pipeline shows leads by stage.
Team Performance: top teams ranked by won deal value in the selected period.
Upcoming Follow-ups: pending or overdue follow-ups/meetings within the selected range, ordered mainly by nearest due date.
Recent Deals: recently created deals in the selected range, limited to stages P1, P2, P3.
AI Insights: static hardcoded notes right now, not live calculated data.
How Filter Works

The filter is the date filter at the top from DashboardDateFilter.jsx (line 1). It sends period, month, quarter, year, and range to the backend. Date logic is handled in dashboardRange.admin.js (line 88).

Simple filter behavior:

Monthly: shows data for the selected month and year.
Quarterly: shows data for the selected quarter (Q1, Q2, Q3, Q4) and year.
Yearly: shows data for the selected year.
Examples:

If you choose Monthly + May 2026, dashboard uses May 1, 2026 to May 31, 2026.
If you choose Quarterly + Q2 2026, dashboard uses April 1, 2026 to June 30, 2026.
If you choose Yearly + 2026, dashboard uses January 1, 2026 to December 31, 2026.
Conditions To Show Data

Dashboard includes only active, non-deleted, non-admin users in most admin metrics.
Deals are ignored if is_deleted = true.
Leads are ignored if deleted or inactive.
Follow-ups are ignored if deleted.
Section-wise conditions:

Revenue Won: deal must be P7 and actualCloseDate must be inside selected range.
Active Deals: deal must not be P6 or P7 and must not be deleted.
Win Rate: only closed deals are used, meaning P7 won and P6 lost, based on actualCloseDate.
Pipeline Value: only open deals are summed.
Open Leads: lead must be active, not deleted, not converted to deal, and stage must not be P7.
Lead Pipeline: lead must not be deleted, not converted, and stage must be one of P1 to P6.
Deal Pipeline: open deals are grouped by stage, and won/lost are added separately.
Team Performance: based on won deal value by team members in the selected date range.
Upcoming Follow-ups: record must be followup or meeting, status must be pending or overdue, and due date must be inside selected range.
Recent Deals: deal must be created inside selected range and stage must be P1, P2, or P3.
One important detail: changing the top filter refreshes all cards, pipeline, team performance, follow-ups, and recent deals together from these API calls in AdminHome.jsx (line 262).

formula = percentage change from previous to current
Active Deals

Meaning: compares open deals created in current selected range vs previous range.
Condition:
current = open deals created in selected range
previous = open deals created in previous range
shown value = current - previous
Win Rate

Meaning: shows how much win rate changed compared to previous period.
Condition:
current win rate = won / (won + lost) in selected range
previous win rate = same formula for previous range
shown value = current win rate - previous win rate
if no won/lost deals, win rate is 0%
